# CozyDreams App: Full Feature List

## Overview

CozyDreams brings together creative expression, gentle journaling, ambient interaction, and kind social exploration in a unified pastel-themed experience.

---

## Feature & Component Breakdown

### 1. Room Decorator (`RoomDecorator`)
- Drag-and-drop furniture, wall art, plants, and room lighting.
- Layers backgrounds with gentle animations (e.g., floating clouds, glows).
- Change room mood with “vibe” overlays and lighting.
- All changes are live-previewed.
- Unlock new items via achievements or kindness.

### 2. Avatar Customizer (`AvatarCustomizer`)
- Select base avatar, clothing, accessories, mood/pose expressions.
- Layer assets to create a unique, expressive figure.
- All customizations reflect instantly in the profile and room.

### 3. Journal (`Journal`)
- Daily prompt (text + optional audio entry).
- Calendar view for tracking/jumping to past entries.
- Pin quotes to room wall.
- Journaling unlocks decor rewards (Hearts).
- Journals are always private by default.

### 4. Explore (`Explore`)
- Scrollable grid of other user rooms, organized with soft transitions.
- Visit any public room; admire, gain inspiration, and leave a positive note.
- “Secret guest” visits bestow surprises.

### 5. Shop (`Shop`)
- Browse pastel decor, wallpapers, plants, and cozy extras.
- Preview furniture and wallpaper directly in a mini room pop-in.
- Purchase with earned Hearts/Stars.
- Floating animation on purchase, confetti unlock.

### 6. Profile (`Profile`)
- View main avatar and profile details.
- Set room “vibe,” main scent, and playlist.
- Show off earned rewards, select favorite decor and pin quotes.
- Edit profile with comforting prompts and affirmations.

### 7. Music Player (`MusicPlayer`)
- Soft lofi/ambient music playlists.
- Toggle between themes; audio gently fades on transition.
- Music always accessible from floating widget.

### 8. Rewards (`Rewards`)
- Hearts: Earned from journaling.
- Stars: Earned for visiting, kindness, or sharing inspiration.
- Rewards visualized with soft particle effects.

### 9. Kind Notes (`KindNotes`)
- Leave gentle, anonymous messages to others’ rooms.
- Notes filtered for kindness, displayed as floating word bubbles.

### 10. Whisper Bubble (`WhisperBubble`)
- Daily positive affirmations pop up on home screen.
- Users can save or journal their response.

### 11. Secret Room Guests (`SecretGuests`)
- Periodic mystical floating creatures visit your room and leave a small surprise or message; animated and interactive.

### 12. Floating UI & Animations
- All UI presented in softly rounded, floating cards.
- Consistent gentle entrance/exit animations throughout.

---

## Additional Planned Features

- Accessibility: Screen reader support, high-contrast toggle.
- Persistent local save for decor, avatar, and unlocked assets.
- API integration: Secure and privacy-respecting.
- Theming: Future support for seasonal/holiday event themes.

---

All features combine to create a warm, safe, whimsical space for self-expression, creativity, and gentle social connection.
